Description

Swiftgram is a modded client for Telegram with Lots of features, focus on Privacy, No Limits, No Ads. Completelly Open Source and includes all latest updates from Telegram plus UNLIMITED ACCOUNTS: Add as many numbers as you want for FREE. ACCOUNTS BACKUP: Log-in to your accounts without SMS-code. Restore all Sessions that are still Active on Telegram servers. MESSAGE FILTER: Reduce visibility of SPAM, promotions and annoying messages. FORMATTING PANEL: Bold, Italic, Links? Formatting with just a single tap. VOICE-TO-TEXT: Transcribe audio messages to text for FREE. TRANSLATOR: Real-time translations for an entire chat. Translate messages you send with a single tap. STORIES: Hide stories or disable swipe for recording. APPLE WATCH COMPANION: Send and Receive Text and Voice messages on your Watch, only in Swiftgram! CHAT MANAGEMENT: Control Tabs, Hide "All Chats", move Folders to bottom and remember the last opened Folder to quickly jump into the discussion. HIDE NOTIFICATIONS: No more Pinned Messages or @mentions when you need some piece of mind. 50+ CUSTOMIZATIONS: Tabs, Chat List and Folders, Profiles, Stories, Translator, Better Photos, Stickers, Context Menu and much, MUCH MORE! SIMPLICITY: Swiftgram remains easy to use with no interface clutter. PRIVACY-FOCUSED: Instant Passcode Lock, Completelly Open Source, No Ads, No Trackers. Your messages and chats remain secure. ACCESSIBILITY: Improved VoiceOver support for Messages Sharing, cause A11y matters! Follow the news: @swiftgram Discuss: @swiftgramchat Swiftgram is an unofficial fork based on Telegram API.
